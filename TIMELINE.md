Derived from the live [hookshotgithub.com/status/](https://hookshotgithub.com/status/) page and later public editorial rechecks. Times that originated in UTC are also shown in Asia/Shanghai (UTC+8). This is not a legal finding. Version numbers below that are marked as earlier checks are historical; current listed tags are those confirmed on 2026-11-24.

## 2026-11-05 — Nintendo releases the remake

Nintendo’s product page dates the Switch 2 *Ocarina of Time* remake to November 5. This is the console release that the unofficial PC projects target.

## 2026-11-07 — The PC approach is reported

[DSOGaming](https://www.dsogaming.com/news/the-legend-of-zelda-ocarina-of-time-remake-gets-an-unofficial-pc-port/) reports Hookshot and its local Builder workflow, linking the project on November 7, 2026.

Contemporary reporting describes the repository and account disappearing around November 13. A reported 12:50 GMT check is not an independently verified outage start time. The cause remains unconfirmed. A 404 alone cannot distinguish deletion, account suspension, a private repository, or a copyright complaint.

## 2026-11-15 — Hookshot publishes on Forgejo

On 15 November 2026, NotRexed published Hookshot on its Forgejo instance at [git.notrexed.dev/Hookshot/Hookshot](https://git.notrexed.dev/Hookshot/Hookshot). v2.3.0 appeared at 04:32:50 UTC (12:32 Asia/Shanghai), the first stable release since v2.1.0 (v2.2.0 was only a candidate); official notes mention a dedicated render thread, less stutter, and about 305 fixes. v2.3.1 followed at 05:08:36 UTC (13:08 Asia/Shanghai): official notes say the Windows Builder is no longer stuck on “Looking for your game files…” with an unresponsive USB, cloud or network drive; on Linux, the v2.3.0 AppImage failed with 'stdio.h' file not found / a missing compiler, which v2.3.1 fixed; and a first Linux build is faster because the AppImage carries precompiled third-party code, skipping about 315 files. The current official Hookshot stable, as last successfully verified from that release page, is v2.3.2, published at 22:52:17 UTC the same day (2026-11-16 06:52 Asia/Shanghai); official notes say “Everything from v2.3.1 is in this release too.” Today’s install should use the current official stable, v2.3.2, from the official release page—not an older tag. A contemporary [SceneGaming](https://scenegaming.com/en/news/hookshot-vuelve-forgejo-2-3-1-ocarina-of-time-switch-2) article reported the Forgejo return and covered v2.3.1; v2.3.2 shipped the same day at 22:52 UTC, and the current stable follows the official release page.
